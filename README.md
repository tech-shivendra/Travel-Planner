# ✈️ Travel Planner Web App

**Travel Planner** is a front-end web application designed to help users explore and plan travel destinations through a simple and interactive interface. The project focuses on clean UI design and basic JavaScript functionality.

## 🔗 Live Preview

👉 https://tech-shivendra.github.io/Travel-Planner

## 📖 About the Project

This project was created to practice:
- Front-end web development
- UI styling using CSS
- JavaScript-based interactivity
- Organizing a small web project structure

## ✨ Key Highlights

- Responsive web layout  
- Interactive elements using JavaScript  
- Organized folder structure  
- Beginner-friendly and easy to extend  

## 🧰 Built With

- HTML  
- CSS  
- JavaScript
